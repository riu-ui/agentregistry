QUESTIONS

Frequently asked

What is an Agent ID?

A non-transferable .ai identity issued inside the Binance App, one per user, recorded as an ERC-721 on BNB Chain. Agent Registry reads it on-chain — no account, no signup, no password.

Does signaling cost anything?

Only BNB gas for the transaction. The registry holds no funds and charges no fee.

Who can submit or signal?

Any wallet holding an Agent ID. One ID, one signal per project — enforced by the contract, not by an admin.

Can a listing be removed?

No. There is no owner and no delete function. A bad listing stays visible — but flags push its score down, and everyone can see the upvote/flag ratio.

Is a high score a safety guarantee?

No. Scores are community signals, not audits. Always do your own research before interacting with any project.

Why is a project missing?

The directory only lists what holders submit. If a project isn't here, no holder has submitted it yet — submit it yourself if you hold an Agent ID.
